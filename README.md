# 핑퐁게임 (개인)

- 무엇: 휴대폰용 탁구(핑퐁) 게임. 단일 HTML 1개(`index.html`, 49KB, 얼굴 사진·소리 내장).
- 원본: 일반 클로드(claude.ai) 대화에서 만든 파일을 `Downloads\index.html`로 받아 그대로 복사(코드 수정 0).
- 배포: GitHub 저장소 `pingpong`(공개) → GitHub Pages.
  - 링크: https://ryuyoungsun308795.github.io/pingpong/
- 재배포(게임을 고친 뒤): 이 폴더에서 `git add index.html && git commit -m "수정" && git push` → 1~2분 뒤 링크에 반영.
- 규칙: 먼저 5점 승리, 칠 때마다 5.5% 가속(최대 1.95배), 컴퓨터=쉬움.
- 주의: 공개 저장소이므로 주소를 아는 사람은 누구나 열 수 있음(얼굴 사진 내장). 비공개로 돌리려면 저장소를 private로 바꾸고 다른 호스팅(아티팩트 등)으로 옮겨야 함.
