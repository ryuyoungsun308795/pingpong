# JEA's Pingpong (개인 · 휴대폰 탁구 게임)

## 무엇
- 휴대폰용 탁구(핑퐁) 게임. 단일 HTML 1개(`index.html`, 약 64KB, 제아 얼굴 PNG·소리 합성 코드 내장).
- 원본: 일반 클로드(claude.ai) 대화에서 만든 `Downloads\index.html`(2026-09-13 수신). 1차 개편본은 `_과거버전\2026-09-13_2110\index.html`.

## 파일
- `src_index.html` — 사람이 읽는 소스. 얼굴 PNG 자리는 `__FACE_LINE__` 한 줄.
- `_과거버전\face_line.js` — 얼굴 PNG base64 한 줄(`var FACE_SRC = ...`).
- `index.html` — 배포본. **직접 고치지 말고** `src_index.html`을 고친 뒤 아래 명령으로 다시 만든다.
  - `sed -e '/__FACE_LINE__/{r _과거버전/face_line.js' -e 'd}' src_index.html > index.html` (Git Bash)
- `qa_play.py <출력폴더> win|lose` — 자동으로 한 판(완벽 플레이/정지 플레이) 돌려 레벨 상승·승패·말풍선·콘솔오류를 JSON으로 출력.
- `qa_shots.py <출력폴더>` — 데스크톱·가로·작은 폰 화면 캡처.

## 2026-09-13 개편 내용(류영선 지시 7건)
1. 첫 화면에 제목 등장(글자가 차례로 떠오르는 애니메이션) · 2. 제목 "JEA's Pingpong"(Fraunces 이탤릭)
3. 살아남을수록 난이도 상승: 레벨 1~9, `압력 = 플레이시간/13 + 랠리 타수/8` 정수부+1. 레벨이 오르면 공 기본속도·가속·제아 막대 속도↑, 제아 조준오차·내 막대 폭↓(`tuning()` 함수). 레벨 칩(우측 상단)이 튀며 효과음.
4. 음악: 88bpm 로파이 재즈(Fmaj7·Em7·Dm7·Cmaj7·G7 8마디, EP 코드·베이스·킥/스네어/스윙 하이햇·멜로디·리버브·바이닐 노이즈). 레벨·랠리에 따라 템포 최대 1.45배. 효과음(타격=음계 상승, 득점, 레벨업, 승/패 팬파레).
5. 디자인: 포슬린 바탕(#F4F2EE)·잉크(#14181F)·나=파랑(#2F6BFF)·제아=코랄(#F0634F), SUIT 글꼴(별표4), 점수 42px 상단 중앙, 잔상·타격 잔광·서브 파문.
6. 제아 얼굴 cover(화면 꽉 채움)·투명도 0.22, 입이 화면 70% 높이에 오도록 배치(넓은 화면은 눈~입 구간).
7. 사람이 이기면 입 옆에 "goood" 말풍선(흰 카드·꼬리) + 얼굴 투명도 0.5로 또렷해짐.
- 부수: 빠른 공이 막대를 뚫는 문제(터널링) 방지용 경로 판정, 화면 이탈 시 음악 정지·복귀 시 재개, `window.__pp` 검증용 창.
